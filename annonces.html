Campagne de rentrée PIX – obligatoire

PIX est le service qui valide les compétences numériques. La campagne de rentrée est obligatoire pour tous les élèves du lycée, quel que soit le niveau.

  • Connectez-vous à PIX en passant par l'ENT (voir le tutoriel ci-dessous), puis saisissez le code de campagne de la classe.
  • À faire sur un ordinateur : la campagne ne fonctionne pas sur smartphone.
  • À terminer avant le 1er décembre 2026, dernier délai.

Code de campagne PIX de la classe : PHPBZK666

⚠ Ne créez pas un 2ᵉ compte PIX : vous êtes déjà inscrit(e).
